دليل رفع وتشغيل نظام CMMS معمل المرجان على الاستضافة الخارجية

تم تجهيز هذه الحزمة خصيصاً لتعمل مباشرة على أي استضافة تدعم PHP (مثل cPanel، Hostinger، Apache، LiteSpeed، Nginx أو XAMPP المحلي) دون الحاجة لتثبيت Node.js أو Vite على السيرفر الخارجي.

محتويات الحزمة:

  • index.php: الملف الرئيسي الذي يقوم بتحميل الواجهة المتطورة وتلقين البيانات المخزنة فوراً.
  • api.php: واجهة البرمجة (REST API) لحفظ التعديلات، أوامر العمل، والعدادات تلقائياً.
  • data_store.json: قاعدة البيانات الشاملة (41 ماكينة، 9 صالات، 12 جهاز قياس، 8 خطط صيانة، 11 صنف قطع غيار).
  • assets/: ملفات JavaScript و CSS المجمعة بأعلى كفاءة وسرعة.
  • .htaccess: ملف إعدادات خادم Apache لضغط البيانات وتفعيل التوجيه التلقائي.

خطوات الرفع على cPanel (خلال دقيقتين):

1 تسجيل الدخول إلى لوحة تحكم الاستضافة:

ادخل إلى cPanel أو لوحة تحكم استضافتك وافتح File Manager (إدارة الملفات).

2 الانتقال إلى المجلد العام للموقع:

افتح مجلد public_html (أو مجلد فرعي إذا أردت تشغيله في مسار مثل cmms/).

3 رفع الملفات وفك الضغط:

ارفع ملف cmms_almorjan_php_package.zip، ثم اضغط عليه بالزر الأيمن واختر Extract (فك الضغط).

4 التأكد من الصلاحيات والتشغيل:

تأكد من أن ملف data_store.json يحمل صلاحية كتابة (Permission 644 أو 666) حتى يتمكن خادم PHP من حفظ التعديلات وأوامر العمل الجديدة.

افتح رابط موقعك ومبروك! سيعمل النظام بكامل مميزاته ورسوماته التفاعلية فوراً.

التشغيل المحلي عبر XAMPP أو سطر الأوامر:

إذا أردت تشغيله محلياً عبر سطر الأوامر:

php -S localhost:8000

ثم افتح المتصفح على http://localhost:8000.
