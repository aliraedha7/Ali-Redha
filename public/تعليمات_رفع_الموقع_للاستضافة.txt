دليل رفع واستضافة نظام إدارة صيانة مصانع الطباعة المرنة (CMMS)
====================================================================

تم تجهيز وبناء كامل ملفات المشروع وتجميعها (Production Build) لتكون جاهزة 100% للرفع المباشر على أي استضافة ويب.

--------------------------------------------------------------------
أولاً: محتويات هذا المجلد (المجلد الجاهز للرفع):
--------------------------------------------------------------------
1. index.html              -> الصفحة الرئيسية للتطبيق مدمجة ومحسنة بأعلى أداء.
2. مجلد assets/            -> يحتوي على أكواد JavaScript و CSS وملفات التنسيق والأيقونات.
3. ملف .htaccess           -> مُعد مسبقاً لسيرفرات Apache / cPanel / LiteSpeed لمنع ظهور خطأ 404 وتفعيل ضغط Gzip.
4. ملف _redirects          -> لمنصات Netlify و Cloudflare Pages.
5. ملف vercel.json         -> لمنصة Vercel.
6. ملف nginx.conf          -> مثال إعداد جاهز لسيرفرات Nginx (VPS).

--------------------------------------------------------------------
ثانياً: خطوات الرفع على الاستضافات المشتركة (cPanel / Hostinger):
--------------------------------------------------------------------
1. ادخل إلى لوحة تحكم الاستضافة (cPanel أو hPanel).
2. افتح "إدارة الملفات" (File Manager).
3. انتقل إلى المجلد الرئيسي للموقع:
   - عادة ما يكون: public_html أو www
4. ارفع كافة الملفات والمجلدات الموجودة في هذا المجلد (أو قم بضغطها في ملف zip ورفعها ثم فك الضغط).
5. تأكد من وجود ملف .htaccess داخل public_html (قد يكون مخفياً؛ فعّل خيار "Show Hidden Files" في cPanel).
6. افتح رابط موقعك ومبروك، التطبيق سيعمل فوراً وبسرعة فائقة.

--------------------------------------------------------------------
ثالثاً: الرفع المجاني السريع عبر Netlify أو Vercel:
--------------------------------------------------------------------
- Netlify:
  1. ادخل على netlify.com وسجل الدخول.
  2. اسحب هذا المجلد بالكامل (Drag & Drop) إلى خانة "Deploy your site".
  3. سيعمل التطبيق خلال 5 ثوانٍ مع رابط مجاني وشهادة SSL تلقائية.

- Vercel:
  1. ادخل على vercel.com وقم برفع المجلد أو ربطه مع مستودع GitHub.

--------------------------------------------------------------------
ملاحظات تشغيلية هامة:
--------------------------------------------------------------------
- التطبيق يعمل بنظام Single Page Application (SPA) ولا يحتاج إلى تثبيت Node.js على الاستضافة العادية؛ فهو يعمل على أي استضافة HTML/JS ثابتة أو مشتركة (Shared Hosting).
- جميع خطوط Cairo و JetBrains Mono متصلة عبر CDN وتعمل بسلاسة.
- البيانات الحالية تعمل بمخزن محلي فوري (Local State & Session) متوافق مع كافة الأجهزة والمتصفحات والشاشات اللوحية.
