# نظام إدارة الصيانة المحوسب (CMMS) - معمل المرجان للمطبوعات والتغليف
## حزمة التشغيل بلغة PHP & HTML5 & MySQL

تمت إعادة كتابة وبرمجة النظام بالكامل باستخدام **PHP و HTML5 و Tailwind CSS و MySQL** مع المحافظة على كافة البيانات، المعدات، أوامر العمل، محطات الخدمات المركزية، وتقارير الدوريات والتسليم والتسلم الهندسي.

---

### 🚀 خيارات التشغيل المتاحة:

#### 1. التشغيل الفوري والسريع (بدون إعداد خادم قاعدة بيانات - وضع Fallback التلقائي):
النظام مزود بمحرك حفظ JSON تلقائي (`data_store.json`) يعمل فوراً عند عدم توفر MySQL، مما يمكنك من تشغيل النظام بمجرد تشغيل خادم PHP:
```bash
cd php_cmms
php -S localhost:8000
```
ثم فتح المتصفح على: `http://localhost:8000`

---

#### 2. التشغيل على سيرفر محلي (XAMPP / WAMP / Laragon):
1. قم بنسخ مجلد `php_cmms` كاملاً وضع محتوياته داخل مجلد `htdocs` (في XAMPP) أو `www` (في WAMP).
2. افتح **phpMyAdmin** عبر: `http://localhost/phpmyadmin`.
3. أنشئ قاعدة بيانات جديدة باسم: `almorjan_cmms`.
4. اضغط على **استيراد (Import)**، ثم اختر الملف: `database/schema.sql` واضغط على **انطلق (Go)**.
5. في حال كانت كلمة مرور MySQL في جهازك ليست فارغة، يمكنك تعديلها في الملف:
   `config/db.php`
   ```php
   define('DB_HOST', 'localhost');
   define('DB_USER', 'root');
   define('DB_PASS', 'كلمة_المرور_هنا');
   define('DB_NAME', 'almorjan_cmms');
   ```
6. افتح المتصفح وتوجه إلى: `http://localhost/php_cmms` أو `http://localhost`.

---

#### 3. الرفع على استضافة ويب حقيقية (cPanel / Plesk / Apache / Nginx):
1. قم بضغط محتويات مجلد `php_cmms` إلى ملف ZIP.
2. ارفعه إلى المجلد الرئيسي لموقعك `public_html` عبر **File Manager**.
3. قم بفك الضغط (Extract).
4. أنشئ قاعدة بيانات MySQL ومستخدم من خلال لوحة تحكم cPanel.
5. استورد ملف `database/schema.sql` من خلال phpMyAdmin.
6. عدل اسم قاعدة البيانات واسم المستخدم وكلمة المرور في ملف `config/db.php`.

---

### 📂 محتويات وهيكلية الحزمة البرمجية:
- `index.php`: لوحة التحكم والمراقبة الرئيسية وقياس المؤشرات (KPIs) والجاهزية.
- `work_orders.php`: أوامر العمل والصيانة وتعديل الحالات والتكليفات والطباعة.
- `shift_reports.php`: تقرير الدوريات الميدانية، بنود الفحص، والتسليم والتسلم الهندسي مع نمط المطور.
- `equipment.php`: سجل الماكينات والخطوط الفنية حسب القاعات (الروتو، الفليكسو، البولي إيثيلين، الأكياس، اللامينيشن، الخدمات المركزية).
- `preventive_maintenance.php`: خطط الصيانة الوقائية الدورية (أسبوعية، شهرية، سنوية).
- `inventory.php`: مستودع قطع الغيار ومتابعة حد الأمان الأدنى وصرف المواد.
- `meters.php`: قراءات ومؤشرات المحطات المركزية (الضواغط أطلس كوبكو، التشيلرات دايكن، البويلرات، مغذيات UPS شنايدر).
- `team.php`: الهيكل الفني للمهندسين وفريق الصيانة.
- `config/db.php`: ملف اتصال قاعدة البيانات مع دعم التخزين المؤقت المباشر.
- `database/schema.sql`: سكربت قاعدة بيانات MySQL الكامل مع كافة البيانات الأولية لمعمل المرجان.
- `includes/`: القوالب العلوية، الجانبية، والقوائم السفلية المتجاوبة مع الهواتف والشاشات الكبيرة.
